## 0. 总原则(所有 Lab 通用)

1. **现象先行**:每个 Lab 动手前先写"你将在板上看到什么",动手后逐条对号。写作者拿不到现象的 Lab 不许开写。
2. **统一文件范式**(继承 lab01,每 Lab 一目录):
   - `<module>.v` 参考实现(逐行注释)
   - `labNN.xdc` 约束(三要素:PACKAGE_PIN / IOSTANDARD / create_clock)
   - `tb_<module>.v` 仿真测试平台(带自检,结尾打印 PASS/FAIL)
   - `build.tcl` 一键五步舞(综合→实现→比特流,尾部追加资源/时序报告)
   - `sim.tcl`(xvlog/xelab/xsim 三步,或直接给 shell 一行)
   - `program.tcl`(JTAG 烧写三连:connect → program,~15 行)
   - `README.md` 实验报告式(目的/现象/步骤/思考题)
3. **参数化提速仿真**:所有含长计数的模块(消抖 20ms、UART 434 分频)带参数(`STABLE_CYCLES`、`BAUD_DIV`),板上用真值,TB 里可覆盖小值快速跑 + 一次真值慢跑。这本身就是教学点("仿真时间和真实时间不是一个时间")。
4. **资源账本**:build.tcl 尾部 `report_utilization`,每课 README 里记一行 LUT/FF 用量——学员第一次看见"我的电路吃了多少芯片",呼应 ch00 的电路思维。
5. 板上只有 **1 LED + 1 按键 + 2×40pin 排针**。所有"多输出"需求用三种手段变现:时间复用(闪烁节奏/呼吸)、PWM 亮度、排针飞线(杜邦线就是我们的"外设")。

## 3. Lab02 · 按键消抖(需求书已布置,保留"先自己写再看参考")

- **硬件现象(本课灵魂,对比实验)**:
  1. 先烧"裸版":`key_toggle_raw.v`(裸按键直接 toggle LED,~20 行)。现象:按一次,LED 可能翻 0/1/2 次——**乱翻,且每次不一样**。快速轻按最容易复现。
  2. 再烧"消抖版":按一次,翻一次,连按 50 次零失误。
  3. 两版都在板,学员自己念出区别——这一课的"aha"不在代码在指尖。
- **引脚/外设**:无新(N18/P14/R14)。
- **代码规模**:`key_toggle_raw.v` ~20 行;`debounce.v` ~55 行(参数 `STABLE_CYCLES = 20ms×50MHz = 1_000_000`,计数器稳定满→输出单周期脉冲 `tick`);`key_toggle.v`(tick→翻转 LED)~25 行;`tb_debounce.v` ~85 行(含抖动模型 task:按下后 5ms 内插入 3~5 次随机毛刺;断言:每个抖动后 tick 恰好 1 个、且在 20ms 稳定之后)。
- **仿真方案**:TB 骨架已布置。快速跑(参数缩到 2ms)+ 真值慢跑(20ms×几十次按键 = 仿真时长 ~1.5s 真实时间,XSIM 秒级跑完,无压力)。波形里肉眼数:毛刺期间计数器清零重数——**"计数器被毛刺按在地上摩擦"的波形截图**是本课第二现象。
- **上板步骤**:build.tcl → 看 WNS≥0 → program.tcl → 对比两版 → (选)把 R14 改接 `cnt[22]` 之类乱点验证学员自由发挥。
- **已知坑**:①按到 RST 键=现象全灭(见 §0.1,本课必须讲,消抖课手在按键区);②裸版有时"看起来也正常"——抖动本身是概率,教"多按几次";③TB 里 `#` 延时的时间单位由 timescale 决定,别写出 20ms 变 20ns 的假通过。
- **文件清单**:`key_toggle_raw.v` / `debounce.v` / `key_toggle.v` / `lab02.xdc` / `tb_debounce.v` / `build.tcl` / `sim.tcl` / `program.tcl` / `README.md`。

## 4. Lab03 · 亚稳态与跨时钟域(原"打两拍",建议改造)

**建议改动**:原路线 Lab03 名为"亚稳态与打两拍",但亚稳态在板上永远看不见(MTBF 以年计),直接上会违反"现象先行"。改为**"看不见的敌人:亚稳态与跨时钟域"**,现象三层:

- **第 1 层(仿真,主现象)**:TB 用两个**真异步**时钟(如 20.000ns 与 20.003ns——XSIM 时间精度 1ps 支撑得起)驱动一个 binary 计数器跨域采样,几微秒仿真时间内**必然**抓到撕裂值(如 7→15,因为 0111→1000 各位不同时翻转);同条件下 Gray 编码版永远干净。两个波形图并排放,这是全课最有力的一张图。
- **第 2 层(仿真,人为亚稳态)**:TB 里 `force` 同步器第一拍输出为 `1'bx` 一拍,展示:不打包就透传;打两拍后第二拍大概率收敛到 0 或 1——"亚稳态会自己好,但要给它一个时钟节拍的时间"。
- **第 3 层(板上,正确版)**:`key → sync2ff(打两拍) → debounce → tick`,把 Lab02 的输入链升级成"生产级"。现象:和 Lab02 一样稳定——**这正是要点**:板上永远不坏,但 MTBF 计算告诉你它可能在 2037 年某个下午坏一次。给 MTBF 公式 + 代入 50MHz 的数量级结果。
- **板上彩蛋(选做,标注实测)**:双 PLLE2(如 100MHz 与 99.5MHz,同 50MHz 参考)驱动 binary-vs-Gray 撕裂,差拍 ~2µs 扫一遍采样相位,错误版 LED 节奏抖、Gray 版平稳。**写课时先实测可见性,不明显就砍**,以仿真层为准。
- **新依赖**:第一个 IP——clocking wizard(`create_ip` 纳入 build.tcl,脚本化生成,不点 GUI)。这本身是工具课 A 的预告素材。
- **代码规模**:`sync2.v` ~20 行;`cdc_demo.v`(binary/Gray 计数器+双采样,含彩蛋注释版)~90 行;`key_chain.v`(升级版按键链)~30 行;`tb_cdc.v` ~90 行;`tb_metastab.v` ~40 行。
- **引脚**:无新(彩蛋版也无新,全片内)。
- **已知坑**:①clk_wiz 的 IP 生成要写进 build.tcl(`create_ip ... generate_target`),否则一键化断裂;②两个"仿真异步时钟"的相位漂移要够小,撕裂才像真实 CDC 而非暴力错位;③`force` 语句只能用在 TB,RTL 里没有这回事——提前声明,防学员模仿。
- **文件清单**:`sync2.v` / `cdc_demo.v` / `key_chain.v` / `lab03.xdc` / `tb_cdc.v` / `tb_metastab.v` / `build.tcl`(含 IP 生成)/ `sim.tcl` / `program.tcl` / `README.md`。

## 6. Lab05 · UART 收发与自环(原"发送器",建议扩展为收+发)

**建议改动**:原路线只做发送器,但"发"在板上没有观察者(CH340 接的是 PS UART,PL 的 TX 出不去)。**补上接收器 + 排针自环**,让板子自己当自己的串口对端——TX 和 RX 都有现象,还多教一个 RX 状态机。

### 6.1 UART 观测三路方案(裁定)

| 路径 | 需要 | 现象 | 角色 |
|---|---|---|---|
| **A. 排针自环回(主路径)** | 杜邦线 1 根 | TX 脚与 RX 脚(GPIO1 相邻两脚,如 U12↔W16)短接:按一次 PL_KEY → 板子发 "Hello FPGA\r\n" → 自己收到 → 收到首个字节即翻转 LED | **主线**,零新硬件,同时验证 TX+RX 全链路 |
| **B. ILA 抓波形(工具课 C 联动)** | 无(ILA 是免费档) | 波形窗逐位解出 'H'=0x48:起始位低、8 数据位 LSB 在前、停止位高——"原来串口波形长这样" | 波形教学的最佳载体,ILA 课直接复用本工程 |
| **C. USB-TTL 转 PC(选做)** | USB-TTL 模块(¥10,3.3V LVCMOS 电平,**别买 RS232 电平的**) | PC 上 `minicom 115200` 直接看到板子打的字,键盘发 '1'/'0' 控板载 LED | 选做彩蛋,给"想看 PC 终端"的学员;附录给购买规格 |

### 6.2 设计要点

- **硬件现象**:自环模式下,PL_KEY 按一次 → LED 翻转一次 + (ILA 里)一帧波形 + (选做 PC 上)一行 Hello。"板子说了一句自己听得懂的话"。
- **参数**:115200-8-N-1;50MHz/115200=434.03(误差 0.01%,完美);RX 在位中央采样(tick+217)。
- **代码规模**:`uart_tx.v` ~85 行(IDLE/START/DATA/STOP 状态机 + tick 生成);`uart_rx.v` ~80 行(起始位检测+中点采样);`uart_top.v` ~50 行(debounce 例化 + 按键触发发送 + 收到字节翻转 LED);`tb_uart.v` ~120 行(发 256 个随机字节自环回读比对,误码=0 才 PASS;TB 里 baud 参数缩小提速)。**全课最大 Lab,~340 行**,是"会师"前的总装练习。
- **引脚新增**:TX=U12、RX=W16(GPIO1,均 LVCMOS33;取自厂商 LCD demo XDC 已核实存在的脚)。XDC 加两行+注释"杜邦线短接这两脚"。
- **仿真方案**:字节级自检 + 单帧波形截图讲解帧格式;`$display` 逐字节打印收发对照表。
- **上板步骤**:build → program → **先不插杜邦线**(按键只发不收,LED 不动,讲"没有回路的串口")→ 插线(LED 翻转)→ 故意拔线(又不动)——**插/拔杜邦线本身就是实验变量**,这个"接线即外设"的体验是排针存在的意义。
- **已知坑**:①TX 空闲态必须为高(没数据时线是 1,这是协议的规定动作,接错 LED 会"常亮乱闪");②杜邦线插错排针脚=没现象,附录给排针照片/丝印对照;③选做 C 路径注意共地(USB-TTL 的 GND 接排针 GND)。
- **文件清单**:`uart_tx.v` / `uart_rx.v` / `uart_top.v` / `lab05.xdc` / `tb_uart.v` / `build.tcl` / `sim.tcl` / `program.tcl` / `README.md`(附录:杜邦线接法照片位)。

## 7. 工具课 C · ILA 在线逻辑分析仪(绑定 Lab05)

- **"现象"**:
  1. **肉眼解码 'H'**:触发条件 = tx 下降沿;深度 8192(@50MHz 采样 = 163µs,一帧 86.8µs,抓接近两帧)。波形窗放大,学员自己从 tx 线上读出 0b01001000——"你在用人眼当 UART 接收器"。这是全课最漂亮的时刻。
  2. **按键即触发**:触发词 = Lab02 的 `tick`,按一次抓一次,波形里看消抖计数器真实读数——"逻辑分析仪挂在你的电路上"。
- **免费档 1 核 5 探针的裁定(如实交代)**:
  - UART 工程探针:`tx`、`rx`、`busy`、`bit_cnt[2:0]`(总线算 1 探针)、`state[2:0]` = **恰好 5 个,刚卡线**——教材如实写"免费档上限 5 探针,本书按 5 设计;要更多就得付费档",这本身是很好的一课。
  - 消抖工程:同样凑得出 5 个(`key_raw/key_sync/cnt 高位截断/tick/led`)。
  - 1 核限制:我们全程单时钟域单核,无影响。
  - **不确定点:免费档采样深度上限**(BRIEF 只限核数/探针数;若深度也受限,备选 9600 波特——一帧 289µs@50MHz 采样=14462 点,或降深度分段抓)。写课时用 2026.1 实测,先按 depth=8192 写。
- **集成方式**:build.tcl 里 `create_ip ila` 直接例化(不用 mark_debug 的玄学,显式例化对小白更可控、可脚本化)。
- **已知坑**:①ILA 吃 JTAG——先 `pkill -f openocd`(§0.1);②加 ILA 后 LUT/FF 涨 ~100,资源账本记得对比(又一个教学点);③触发没反应八成是触发条件写成电平而想要沿;④Hardware Manager 认不到板:检查是 JTAG 口那个 type-C 不是串口那个。

## 8. Lab06 · PS-PL 会师(两级设计 + FIQ 验收门)

**前置条件(验收门,课程页面显式写)**:FIQ 修复验证三绿——①`insmod fpgaload.ko fw=lab01.bin` 后 LED 闪;②ssh 仍活;③`/sys/class/fpga_manager/fpga0/state` = operating。当前状态(2026-11-20):GIC 修复 BOOT.BIN 已打包、哨兵脚本等板子断电重启自动执行验收,**写课时若未验收通过,本页发布时挂"前置未满足"横幅**。

- **Level 0 · PS 是 PL 的搬运工(修复验证后即可上)**:
  - 现象:Debian shell 里一条命令加载比特流,PL 的 LED 开始呼吸(Lab04 的 bin)——**"Linux 的一条命令,点亮了 FPGA 里的电路"**。
  - 内容:bit2bin.py(已有,字节序交换原理已在脚本注释里,展开讲 PCAP)+ fpgaload.ko 流程 + 三绿验收。
  - **战地日记(必写)**:FIQ 风暴排查全过程是学员亲历的,写成一页"你经历过的这场调试"——JTAG halt 看 PC、GICD_IGROUPR 安全世界、u-boot 修复——比任何编造的案例都好。
- **Level 1 · Linux 命令点灯(进阶高潮)**:
  - 主方案:Block Design 里 PS7(启用 GP0)+ AXI GPIO IP + 连到 R14 → 生成 bit → bit2bin → fpga manager 加载 → `devmem 0x41200000 32 1` → **LED 亮**。ssh 里敲一行命令,PL 里的电路听令——全课程最大会师时刻。
  - 备选简化:EMIO 路线(PS GPIO 经 EMIO 出 PL 到 R14,Linux /sys/class/gpio 控制,无 AXI 互连,BD 更简单)。二选一,**建议主 AXI、EMIO 作练习**;BD 的 Tcl 脚本化(create_bd_design 全程命令行)延续一键化范式,~80 行 Tcl。
  - 现象链:devmem 写 0/1 ↔ LED 灭/亮;再看 `/sys/class/gpio` 或 AXI 寄存器读回。
- **已知坑**:①AXI 地址(0x41200000)要与 BD 里的 assign 一致,写进 README 对照表;②fpga manager 加载前 bit 必须 bin 化;③FSBL/启动链不动(PS 侧系统不变,只换 PL 比特流)——这正是 Level 0 的意义;④加载新比特流会覆盖 JTAG 烧的旧电路(两种加载方式互斥,现象上"谁后到谁生效")。
- **文件清单**:L0:`load.sh`(bit2bin+scp+insmod 一条龙)+ README;L1:`system_bd.tcl`(BD 生成)+ `lab06_top.v`(~40 行包装)+ `lab06.xdc` + `build.tcl` + README(devmem 命令卡)。

## 11. 本方案的不确定点(供交叉质询)

1. **ILA 免费档采样深度上限**(按 8192 设计,一帧 115200 波特 = 4340 采样,8192 够两帧内一帧半;若深度也受限→降 9600 或分段)——需 2026.1 实测。
2. **clk_wiz / AXI GPIO / ILA 在 2026.1 Standard 免费档的可用性与生成限制**(常规逻辑 IP 历来免费,但 2026 新授权体系需实测确认,尤其 AXI GPIO)。
3. **双 PLL 撕裂彩蛋的板上可见性**(相位扫描差拍 ~2µs,理论可见,未实测;不明显则砍,仿真层兜底)。
4. **GPIO1 物理排针序号 ↔ 封装脚对照表**需要人工读原理图 PDF(pdftotext 乱序,不可自动提炼);Lab05 取的 U12/W16 两脚在物理上是否相邻未知——不相邻就换脚,反正 29 脚任选。
5. **Lab05 选做 C 路径**(USB-TTL)假设学员愿意花 ¥10;若不愿,主线 A/B 已完整闭环,不依赖。
6. **XSIM 150 万周期仿真实测耗时**(估算秒级,未跑过 20ms 全时长消抖仿真;有参数缩放兜底)。

# Zynq FPGA 从零到实战 · 配套课程

> 在自己亲手移植过 Linux 的板子上,从零学会 FPGA(Verilog + Vivado + 数字电路思维)。
> 每一课都跑在你手里的 Z7-Nano(XC7Z020)真硬件上。

[📖 打开课程网站(GitHub Pages)](https://lzjever.github.io/zynq-fpga-course/)

## 这是什么

一套**为"命令行高手 + FPGA 小白"定制**的入门课程:已完成的先修成就——主线 Linux 移植(见[姊妹手册](https://github.com/lzjever/zynq-fpga-course/blob/main/README.md)),从 Verilog 101 心智模型起步,经按键消抖、PWM、UART 状态机,直到 PS(Debian)与 PL(FPGA 逻辑)会师。

**核心承诺**:所有术语首次出现必给全称与中文释义;所有实验可在本板复现;所有代码逐行注释。

## 目录结构

```
docs/    课程网站(纯静态,GitHub Pages 托管)
labs/    每课配套工程(Verilog + XDC + Tcl + 测试台)
build/   课程规划素材(设计依据,公开可溯)
```

## 杜邦线接法(文字版接线图)

```
        Z7-Nano 板上沿(GPIO1 排针区,丝印 GPIO1_xxP/N)
        ┌────────────────────────────────┐
        │  …  U12  …  W16  …              │   ← 两个目标脚,以附录 A 排针表对丝印
        └───┬──────────┬──────────────────┘
            │          │
            └──[杜邦线]─┘        母对母,两头分别插 U12、W16
```

- TX 在 U12,RX 在 W16(电气引脚号;物理相邻与否以板上丝印为准,不相邻没关系)
- **方向没有讲究**:这根线两头接的都是我们自己的脚,不存在"接反"——只要一头在 U12、一头在 W16
- 同一块板上的两个脚,**天然共地**(地就是板子本身)—— 今天不用接 GND;但记住:一旦接**外部**设备(USB-TTL、另一块板),**GND 必须先接** —— 电压是相对值,没有共同的地,"0 和 1"就没有定义。这是第一次飞线要带走的最重要习惯
- 拔线实验前看下面现象表第 3 行

## 现象对照表

| # | 操作 | 现象 | 说明 |
|---|---|---|---|
| 1 | 插杜邦线,按一次 PL_KEY | LED 翻转一次 | 板子发了 'H',自己收到了 |
| 2 | 连按 5 次(间隔 >1s) | LED 翻 5 次 | 每帧都走完全链路 |
| 3 | **拔掉杜邦线**,再按 | LED 纹丝不动 | rx 上拉读恒 1 = 静默;插/拔本身就是实验变量 |
| 4 | 插线但换成 lab06 的 bit(TX 无 RX) | LED 不动 | 那个 bit 里没有接收器 —— 链路两端缺一不可 |

## ILA 解码练习(可选,plain 现象过了再来)

1. `build.tcl -tclargs ila` 重烧;触发设 `rx(probe0)==0`(起始沿)
2. 按一次 PL_KEY,波形冻结
3. **人肉解码**:从 rx 第一个下降沿起,每 8680ns(434 clk)读一位,先 8 个数据位(LSB 起)再停止位;拼出 01001000 = 0x48 = 'H'
4. 对照 `bit_cnt/state` 两根总线,看你的接收机和我(参考实现)的脚步是否一致

## 已知坑

- 杜邦线插到别的脚 = 没现象:回附录 A 对表(U12/W16)
- 拔线后 LED 偶尔自己动:检查是不是碰松了线(半接触 = 毛刺);我们的上拉只在"完全拔掉"时保证静默

# Lab 03 · CDC 撕裂演示(ch03 配套)

亚稳态看不见、摸不着,但它的"多比特版"——数值撕裂——可以在仿真里
确定性复现。本 Lab 两件事:

1. **仿真(主角)**:`tear_demo.v` + `tear_tb.v` —— 双时钟采样一个
   未防护的二进制计数器,亲眼看它撕;格雷码对照组纹丝不动。
2. **上板(正确链)**:把你 lab02 的消抖器回炉成 v2(最前面加两级
   同步器),板上按 50 次验收 + 仿真压测 10 万次。

## 文件清单

| 文件 | 说明 |
|---|---|
| `tear_demo.v` | 二进制 + 格雷码双计数器(故意不防护的"错误示范") |
| `tear_tb.v`  | 双时钟 TB:各位显式延迟注入 + 三路对照自检 + force X 盲区演示 |
| `sim.tcl`    | XSIM 批处理跑批脚本 |

## 命令卡(XSIM 三步舞,在 本 目录下)

```bash
xvlog tear_demo.v tear_tb.v
xelab -debug typical tear_tb -s tear_tb_sim
xsim tear_tb_sim -tclbatch sim.tcl      # 批处理出报表

```

## 预期输出(实测,2026-11,iverilog 12 / XSIM 2026.1)

```
[1133 ns] 撕裂! 上一拍 11 → 本拍 13   (合法值只有 11 或 12)
[1152 ns] 撕裂! 上一拍 13 → 本拍 12   (合法值只有 13 或 14)
[2571 ns] 撕裂! 上一拍 15 → 本拍 7    (合法值只有 15 或 0)
===================================================
 阶段一 · 撕裂统计(共 2028 个有效采样)
   ① 二进制 + 延迟注入 : 86 个撕裂样本   ← 该撕的,撕了
   ② 格雷码 + 延迟注入 : 0 个撕裂样本   ← 对照组,纹丝不动
   ③ 二进制 + 零延迟   : 0 个撕裂样本   ← 理想仿真的假象
===================================================
 盲区演示: force q1 = X 两拍后, q2 = x
 PASS:撕裂已被延迟注入复现;格雷码与理想对照干净。
```

要点:
- 15→7 那发:计数从 15 回 0(1111→0000,四位同变),采样沿落在
  高位已变、低位未变的窗口里,抓到 0111=7。7→8 的镜像撕裂
  (抓到 15)也藏在 40us 里,截图时留意。
- ③ 路零撕裂正是"仿真器盲区"的前半段:理想 RTL 里非阻塞赋值
  让各位原子更新,**必须**手工注入延迟(① 路)才能看到真实世界
  的布线偏斜。

## 波形截图点位(开 `xsim tear_tb_sim -gui`)

1. **`bin_skew[3:0]`**:任选一次 7→8(用"Go to time"跳到撕裂打印
   的时间戳前后)。四位不同时跳:高位(#1)先走,低位(#4)压后。
2. **`s_bin` 撕裂瞬间**:上一拍 11、本拍 13 的那拍(1133 ns),

   格雷码的免疫力,不是运气。

## 板上部分:lab02 → v2 回炉

在**你自己的** lab02 工程里加两行(这就是"打两拍"):

```verilog
reg  [1:0] sync_ff;
always @(posedge clk) sync_ff <= {sync_ff[0], key_raw};  // 两级同步器
wire key_sync = sync_ff[1];
// 原 lab02 中 key_raw 的全部下游(边沿检测、消抖计数)改吃 key_sync
```

- **板上验收**:烧 v2,按 50 次,LED 每次恰好翻一次(顺手再烧
  ch02 的裸版对比:按 20 次大概率撞出双翻/漏翻——那就是抖动 +
  异步两个因子都在作案)。
- **压测(仿真,注意缩参数!)**:真实 20ms 消抖窗口下按 10 万次
  = 2000 秒仿真时间,跑不完。把消抖阈值参数缩到 40 个时钟
  (阈值/间歇同步缩短,节奏放快 25000 倍)再压:

```verilog
// 在你 lab02 的 TB 里(压测版激励):
// 阈值参数改 40(= 800ns);每次电平变化前插随机"异步相位"0~19ns:
initial begin
    key_raw = 0;
    repeat (100_000) begin
        #({$random} % 20) key_raw = 1;               // 按下,异步时刻
        repeat (3) begin #40 key_raw = ~key_raw; end // 抖 3 下(均短于阈值)
        #1000 key_raw = 0;                           // 稳定按下后释放
        #1000;                                       // 间歇
    end
end
// 断言沿用你 lab02 的"单周期脉冲计数器":脉冲总数 == 100_000,
// 多一个少一个都算 FAIL。先跑 1 万次快速确认,再拉满 10 万次
//(约 0.2s 仿真时间,泡杯茶)。
```

- **资源账本**:v2 比 lab02 多 2 个 FF(两级同步器)+ ~1 LUT。
  把数字记进你的账本(ch04 会全班对账)。

## 常见坑

- `force`/`release` 只能写在 TB 里,设计代码里出现必挂综合。
- 别把"仿真 0 撕裂"当成安全证明——③ 路就是反例:没注延迟的
  理想仿真什么危险都看不见。
- 两级同步器之间**不许**再插组合逻辑(第一拍的"半好"值需要
  一整个时钟周期安静收敛,别在半路再采样它)。

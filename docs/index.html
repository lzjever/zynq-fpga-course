课程地图:从这里开始

在你亲手移植过 Linux 的那块板子上,从零学会 FPGA——每一步都跑在真硬件上。

写给"命令行高手 + FPGA 小白"的一门课

你已经用这块 Z7-Nano 亲手完成了主线 Linux 移植:内核、U-Boot、Debian、JTAG 调试,全是你的日常。但这颗芯片的另一半——FPGA——对你还是黑盒。这门课把它打开:从"电路不是程序"的心智模型起步,经消抖、PWM、串口状态机,直到你移植的 Debian 装载你自己写的电路、写你自己设计的寄存器。

核心承诺:所有术语首次出现必给全称与中文;所有实验可在本板复现;所有代码逐行注释;先看见现象,再讲道理。

这门课的一句话

学会用电路的方式处理时间。闪烁是数时间;消抖是量时间(20 毫秒);PWM 是时间的平均;串口是用时间编码信息;总线是两个世界按节拍握手;会师是你的 Debian 的时间与硅片的时间合流。软件里你用 sleep() 和时间戳,电路里只有一样东西:时钟,和数着时钟的计数器。

四座里程碑

M1 · 第一次看见时间(ch01)

上一页留下一个悬案:把 LED 接到计数器第 0 位,它"半亮"——半亮是眼睛对你撒的谎。ch01(仿真入门)里你拿起一台免费的时间显微镜(仿真器),在波形里亲眼看见 25MHz,悬案收案。

M2 · 第一件自产电路(ch02)

按键消抖。不再改别人的代码,而是从一张白纸开始:自己写需求、自己写电路、自己写测试、自己验收。身份从"改代码的人"变成"设计电路的人"——这是全课程最大的一次跃迁。

M3 · 让硅片呼吸、开口说话(ch05-07)

呼吸灯顺着三角波渐亮渐灭;然后板子用你 ssh 上 Debian 的那个波特率,亲口"说"出一帧数据——你用自己的眼睛当接收器逐位解码。课程中后段的续航包。

M4 · 会师(ch08-10)

你移植的 Debian 用 FPGA Manager 装载你写的电路;devmem 一枪打中的寄存器,是你自己设计的。两条技能树在你手里合流——这一座,是给写过 Linux 的你独家定制的。

怎么用本课

每章的固定节奏

钩子(一个反直觉的现象或悬案)→ 目标 → 原理(带图)→ 动手(可复制)→ 现象与验证 → 常见坑 → 小结 + 三档自测。自测固定三档:A 概念(用人话复述)、B 预测(改一处代码,先猜后验)、C 排错(一段带 bug 的代码,素材来自本章的坑)。不考名词解释。

先写后看:两章特殊,机制预告

ch02(消抖)和 ch07(接收器)不给你参考实现——至少一开始不给。流程是:自己写 → 过三关检查点 → 实在卡住才逐级展开提示 → 最后对照参考,写 3 行差异笔记。为什么折磨你?因为"看懂"和"写出"之间隔着一整条鸿沟,而这条鸿沟只能你自己跨。参考实现永远在折叠框里等你,跑不掉。

45 分钟规则(全书通用,先记住)

动手卡壳时,先自己死磕 45 分钟:翻回原理节、画框图、读报错。45 分钟仍无进展,才准展开下一级提示。这是心流的"挑战区"配方——既防呆坐一晚,也防秒看答案。看书看懂了不算会,卡过、错过、修过才算。

先修说明

这门课不假设你有任何数字电路基础,但假设你已完成两件事:

  1. 读完毕业篇 ch00(Verilog 101)并做过 Lab01——你已经建立了"导线/寄存器/时钟"三件套的心智模型,跳过它后面每章都会硌脚。Lab01 的上手教程(GUI 三步 + 命令卡)见 labs/lab01-blink/README.md。
  2. 亲手完成主线 Linux 移植(构建内核、U-Boot、Debian、JTAG 调试)——这是姊妹手册 《Zynq Z7-Nano 主线 Linux 手册》的内容。本课不重复 Linux 侧的知识;到 ch09 会师时,你的移植经验会直接变现:ssh、devmem、FPGA Manager,全是你的老朋友。
提醒 · 板上有一颗会"全清"的按键

板上丝印 RST 的按键是整芯片硬复位:按一下,PL 里你的电路全没,Debian 跟着重启。我们课程用的按键是丝印 PL_KEY 的那颗。现在混个脸熟即可,附录 A 有惨案专页。
